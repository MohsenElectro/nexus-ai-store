# 🚀 AI Nexus Store — پلتفرم فروشگاهی هوش مصنوعی و هاب توکن

یک پلتفرم کامل، پرسرعت و مدرن برای:
1. **فروش اشتراک‌ها و آفرهای ویژه هوش مصنوعی:** ChatGPT Plus، Claude Pro، Midjourney، Cursor و آفرهای تخفیف‌دار دوره‌ای (مانند پکیج جیو).
2. **هاب توکن و پروکسی یکپارچه توسعه‌دهندگان:** اندپوینت کاملاً سازگار با استاندارد OpenAI (`/v1/chat/completions`) با قابلیت استریم SSE، شمارش توکن و کسر لحظه‌ای هزینه از کیف پول.
3. **سیستم مالی و پرداخت دوگانه:** درگاه ریالی شاپرک/شتاب (زرین‌پال) و ارز دیجیتال تتر (USDT / TRC-20) با دفترکل اتمیک و ضد کسر مضاعف (Row-level Locking).
4. **انبارداری رمزنگاری‌شده لایسنس‌ها (Vault):** نگهداری اطلاعات حساس اکانت‌ها با کلیدهای AES-256 و تحویل آنی خودکار، به همراه صف شارژ دستی برای سفارش‌های نیازمند کارت ارزی.

## 🛠️ ساختار پروژه

```
ai-nexus-store/
├── backend/                  # موتور بک‌اند با FastAPI و SQLAlchemy 2.0
│   ├── app/
│   │   ├── api/v1/          # اندپوینت‌های Auth، کیف پول، پرداخت، فروشگاه، سفارش‌ها و پراکسی
│   │   ├── core/            # تنظیمات محیطی، دیتابیس، امنیت و کلیدهای رمزنگاری
│   │   ├── models/          # مدل‌های پایگاه داده (User, Wallet, Product, Order, ApiKey, ...)
│   │   ├── schemas/         # مدل‌های معتبرسازی Pydantic v2
│   │   └── services/        # سرویس‌های کیف پول اتمیک، پراکسی استریم و سفارشات
│   ├── tests/               # تست‌های واحد و تست یکپارچه سناریوی کامل کاربر
│   └── requirements.txt
├── frontend/                 # فرانت‌اند مدرن Next.js 15+ و TailwindCSS
│   ├── src/
│   │   ├── app/             # صفحات، لایوت و استایل‌های راست‌چین و دارک‌مود
│   │   ├── components/      # کامپوننت‌های رابط کاربری
│   │   └── lib/api.ts       # کلاینت تایپ‌اسکریپت اتصال به بک‌اند
│   └── package.json
└── README.md
```

## ⚡ راهنمای اجرای سریع (Quick Start)

### ۱. اجرای بک‌اند (FastAPI):
```powershell
cd backend
# فعال‌سازی محیط مجازی
.\.venv\Scripts\Activate.ps1

# اجرای سرور در پورت ۸۰۰۰
uvicorn app.main:app --reload --port 8000
```
* مستندات خودکار سواگر (Swagger UI): `http://localhost:8000/docs`
* بررسی سلامت سرور: `http://localhost:8000/health`

### ۲. اجرای تست‌های خودکار:
```powershell
cd backend
.\.venv\Scripts\python.exe -m pytest -v
```

### ۳. اجرای فرانت‌اند (Next.js):
```powershell
cd frontend
npm install
npm run dev
```
* دسترسی به وب‌سایت: `http://localhost:3000`
